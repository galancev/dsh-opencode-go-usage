# @astervolans/dsh-opencode-go-usage

[English](README.md) | [中文](README.zh.md) | Русский

> ⚡ Оформить **подписку OpenCode GO**: [buycodingplan.com](https://buycodingplan.com/)

Плагин для [DSH](https://github.com/deepseek-ai/deepseek-harness) (DeepSeek Harness),
который показывает расход квоты **плана OpenCode GO** — подписки за $10/мес с лимитами
на опенсорсные модели по трём окнам: скользящее 5-часовое, недельное и месячное.

Это форк [yumusb/dsh-opencode-go-usage](https://github.com/yumusb/dsh-opencode-go-usage)
([Astervolans/dsh-opencode-go-usage](https://github.com/Astervolans/dsh-opencode-go-usage)),
опубликованный как scoped-пакет `@astervolans/dsh-opencode-go-usage`. Отличие от upstream:
под каждой полосой расхода есть **полоса времени окна** (см. ниже).

Текущая локальная версия — **1.6.0**.

## Что изменилось в 1.6.0 (локальная раскладка)

- **Постоянный виджет в сайдбаре удалён.** Вместо него в нижней панели (composer dock,
  та же строка, где статистика сессии и пилюля баланса) появилась компактная кнопка
  **GO** — слот `conversation.composer.dock`, `order: 1.5`, то есть сразу слева от
  пилюли баланса и справа от статистики.
- **Карточка квоты стала плавающим окном.** Наведение на кнопку открывает поповер над
  ней; клик закрепляет его, чтобы он не закрывался при уходе курсора. Повторный клик,
  `Esc` или клик вне окна закрывают его. Фокус с клавиатуры тоже открывает окно.
- **Кнопка «Обновить» удалена.** Данные обновляются автоматически:
  - один запрос при монтировании кнопки (чтобы `title`/tooltip были актуальны ещё
    до открытия окна);
  - немедленный запрос при открытии окна, если снимок старше 5 минут;
  - повторный опрос раз в **5 минут**, пока окно открыто.
  Закрытое окно показывает последний снимок и сеть не трогает.
- Кнопка доступна с клавиатуры: `aria-haspopup="dialog"`, `aria-expanded`,
  `aria-label` с месячным процентом.

## Возможности

- **Кнопка GO в composer dock** — одна строка нижней панели вместо постоянного блока
  в сайдбаре. Окно позиционируется над кнопкой, ограничивается границами вьюпорта,
  пересчитывается при `resize`/`scroll`; если сверху нет места — раскрывается вниз.
- **Карточка квоты** — три полосы расхода: скользящее окно (5 ч), недельное, месячное.
  У каждой — относительный отсчёт до сброса окна и полоса времени окна: **серый слева —
  прошедшее время** (растёт вправо), **синий справа — оставшееся** (сжимается влево).
  Полосы времени совпадают с полосами квоты по высоте и радиусу (5 px / 3 px), поэтому
  видно, быстрее или медленнее времени расходуется квота. Наведение на полосу времени
  показывает проценты «прошло/осталось».
- В заголовке карточки остаётся бейдж анонимной проверки обновлений npm; сам плагин
  никогда не обновляется автоматически.
- **Команда `/opencode-go`** — выводит те же три окна текстом в любом диалоге.
- **Same-origin прокси** — host-половина регистрирует `GET /opencode-go/usage` и
  проксирует запрос к официальному шлюзу GO с вашим API-ключом. Ключ не попадает в
  браузер, CORS не участвует.
- **Фикс `x-opencode-session`** — во время работы подставляет реальный id сессии
  harness в запросы чата к шлюзу GO (без него шлюз отвечает `400 MissingSessionID`).
  Файлы DSH не патчатся, обновления DSH фикс не затирают.

## Установка

```bash
# 1. установить пакет в профиль web (pnpm; при необходимости corepack enable)
dsh plugin --profile web add @astervolans/dsh-opencode-go-usage

# 2. положить ключ в ~/.dsh/.credentials.yaml
#    OPENCODE_GO_API_KEY: sk-...
# 3. полностью перезапустить dsh web и жёстко обновить страницу
```

Для локальной папки с исходниками:

```bash
dsh plugin --profile web add /path/to/dsh-opencode-go-usage
```

Ключ API берётся из credential-ссылки `OPENCODE_GO_API_KEY` (настраивается полем
`apiKeyEnv`). Полная ссылка на руководство: [docs/INSTALL.zh.md](docs/INSTALL.zh.md)
(китайский, пошагово).

## Конфигурация

Все поля помечены volatile и меняются на странице
Settings → Plugins → Plugin configuration без перезапуска:

| поле | по умолчанию | описание |
|---|---|---|
| `apiKeyEnv` | `OPENCODE_GO_API_KEY` | credential-ссылка / имя переменной окружения с ключом |
| `baseUrl` | `https://opencode.ai/zen/go` | базовый URL шлюза GO |
| `cacheMs` | `30000` | TTL host-кэша апстрим-запроса |
| `updateCheck` | `true` | проверять npm на новые версии (подсказка в карточке и команде) |
| `injectSessionHeader` | `true` | подставлять `x-opencode-session` в запросы чата GO |

## Разработка

Половинки плагина:

| половина | файл | роль |
|---|---|---|
| host (Node) | `lib/index.js` | маршрут `/opencode-go/usage` (`ctx.webServer`), команда `/opencode-go` (`ctx.commands`), ключ через DSH credentials, кэш апстрима (30 с) |
| браузер | `lib/client.js` | рукописный `window.__ModuleLoader__.load({ id, factory })` bundle: слот `conversation.composer.dock` (`order 1.5`), кнопка GO + плавающая карточка |

Проверка:

```bash
npm install          # jsdom + react для тестов
npm test             # 13 jsdom-тестов поведения кнопки и окна
npm run check        # синтаксис lib/index.js и lib/client.js
```

Браузерная половина — рукописный factory-bundle: править нужно `lib/client.js`
напрямую, затем перезапустить `dsh web` и обновить страницу. Изменения host-половины
требуют только перезапуска `dsh web`.

## Диагностика

- **Кнопки GO нет после перезапуска** → жёстко обновите страницу (`Ctrl+Shift+R`):
  boot-graph вставляется при каждой загрузке страницы.
- **`/opencode-go/usage` отвечает 502 «no API key»** → ключ не настроен в
  `~/.dsh/.credentials.yaml`.
- **Шлюз отвечает 401/403** → ключ неверный или подписка закончилась.
- **В карточке строка ошибки** → наведите на кнопку GO (`title` содержит ту же ошибку)
  или откройте карточку и прочитайте строку ошибки.
